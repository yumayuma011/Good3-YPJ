# 今日のいいこと

1日の中であった「3つのいいこと」を記録するためのシンプルな日記アプリです。

ポジティブ心理学のエクササイズ **「Three Good Things」** をもとに、
日々の小さな「いいこと」に目を向け、気軽に振り返ることを目的としています。

毎日の記録をできるだけシンプルにし、無理なく続けられるアプリを目指しています。

## 主な機能

- 1日3つまで「いいこと」を記録
- 過去の記録を確認
- 日付ごとの記録を表示
- カレンダーから記録を確認
- テーマカラーの変更
- デイリー通知
- データのインポート・エクスポート
- 保存されているデータの一括削除

## コンセプト

「いいこと」は、大きな出来事である必要はありません。

おいしいものを食べたこと、天気がよかったこと、仕事や勉強が少し進んだこと、誰かと話したこと、ゆっくり過ごせたこと。

そんな日常の中にある小さな「いいこと」に気づき、記録として残すためのアプリです。

## 画面構成

現在、主に以下の画面で構成されています。

- **記録** — 今日あった「いいこと」を記録・確認します
- **カレンダー** — 過去の日付から記録を振り返ります
- **設定** — 通知、テーマカラー、データなどを管理します

## 使用技術

- **Flutter** — クロスプラットフォームのUIフレームワーク
- **Dart** — アプリ開発に使用しているプログラミング言語
- **Provider** — アプリ内の状態管理
- **flutter_local_notifications** — ローカル通知
- **package_info_plus** — アプリのバージョン情報取得

## データ保存

日記の記録やアプリの設定情報は、端末内に保存します。

現在はアカウント登録や外部サーバーを必要とせず、端末内で利用できるアプリとして開発しています。

将来的にクラウドを利用したバックアップや同期機能を追加する可能性があります。

## 通知

毎日の記録を忘れないように、デイリー通知を設定できます。

通知は端末のローカル通知機能を利用します。
